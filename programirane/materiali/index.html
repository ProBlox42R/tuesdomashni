Osnovni koncepti za C programiranje
int - integer i inicializira promenlivi.
do - do while loop pravi neshto dokato drugo ne se izpulni.
scanf - scanira vhodni danni - input.
print - izvejda danni vo konzolata.
for - cikul for ima 3 mesta vo skobi za (int i = 0; i < n; i++), primer i so toa e po razlichen od cikul while.
if - uslovie.
& - address na promenliva i % e za chislo input/output.
return 0 - zavrshuva programata.
Skobi - treba vinagi da se zatvorat.
